# Exploratory Data Analysis Projects in Python

This repository contains portfolio-ready exploratory data analysis projects using Python.

The projects demonstrate:

- API data extraction
- Data cleaning
- Missing-value handling
- Pandas-based analysis
- Trend and seasonality analysis
- Data visualization
- Analytical reporting

## Projects

| Project | Description | Skills |
|---|---|---|
| Berlin Weather EDA | Analysis of Berlin weather observations using Bright Sky API / DWD data | API, Pandas, missing values, time series, visualization, reporting |

## Tools

Python, Pandas, Requests, Matplotlib, Seaborn, Google Colab
